# Prism IA — UI direction

This project should be **improved in place**, not visually replaced.

## Preserve

- Dark, quiet, editorial Prism identity.
- Existing typography, spacing language, warm neutral palette and thin borders.
- Existing page structure, navigation and product terminology.
- Prism Codex as the premium workspace experience.

## Improve

- Fix interaction bugs before adding new visual systems.
- Prefer small, reversible CSS improvements over replacing the design system.
- Keep Chat, Codex and Studio visually related.
- Keep motion purposeful and respect `prefers-reduced-motion`.
- Render is the production deployment target.

## Do not

- Replace the site with a new unrelated design.
- Add multiple competing CSS systems for the same component.
- Reintroduce Vercel deployment files.
- Fake execution, testing or tool usage in the UI.
